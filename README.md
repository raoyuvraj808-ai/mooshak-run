# 🐭 Mooshak Run

A 3D endless runner game inspired by Lord Ganesha's Mooshak.

## 🎮 How to Play

- Move the Mooshak to avoid obstacles.
- Collect items and keep running.
- Try to achieve the highest score.
- Restart the game after Game Over.

## 🌐 Play the Game

[Play Mooshak Run](https://raoyuvraj808-ai.github.io/mooshak-run/)

## ✨ Features

- 3D endless runner gameplay
- Smooth character movement
- Obstacles and challenges
- Score system
- Game Over and Restart system
- Browser-based gameplay

## 🛠️ Technology

- HTML
- CSS
- JavaScript
- Three.js

The game is inspired by Lord Ganesha's Mooshak and Indian mythology.
